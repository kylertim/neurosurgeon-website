# Michael Y. Oh, MD — Personal Website Starter v5

A custom Next.js starter for a personal academic neurosurgeon website.

## What v5 adds

- Richer photography treatment on the homepage
- A three-image visual story section for technology, communication and patient-centered planning
- Subtle parallax on clinical imagery
- Scroll progress indicator
- Staggered reveal animation for expertise cards
- Refined card hover motion and arrow interactions
- Animated hero details and media treatment
- Improved mobile menu motion
- Full `prefers-reduced-motion` support for accessibility
- No additional animation library or dependency

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
